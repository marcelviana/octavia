===== C.4 — PINÇA de dois dedos, injetada =====
`adb shell input` não tem primitiva de multitoque. O AVD expõe UM device por
contato (virtio_input_multi_touch_1..11), então dois dedos = dois
/dev/input/eventN dirigidos por `sendevent`, que exige `adb root`.

$ adb -s emulator-5554 root        →  restarting adbd as root
$ adb -s emulator-5554 shell id    →  uid=0(root) … groups=…,1004(input),…
$ sh /data/local/tmp/pinca.sh 1080 620 680 320  1480 820 1880 1120   (abrir)
  PINCA-OK
$ sh /data/local/tmp/pinca.sh 680 320 1080 620  1880 1120 1480 820   (fechar)
  PINCA-OK

Oráculo: comparação de pixel do screencap.
  controle (dois screencaps SEM gesto):        0 (0) px diferentes
  pinça-abrir   (1-antes  × 2-depois):    124462 (0,0303862) px diferentes
  pinça-fechar  (2-depois × 3-fechar):    124624 (0,0304257) px diferentes

As três capturas estão em `pinca/`: 1-antes-pinca.png (zoom base, título
visível), 2-depois-pinca.png (partitura AMPLIADA, pautas mais largas, título
rolou para fora), 3-depois-fechar.png (de volta ao zoom base).
  → a pinça do PDF continua funcionando depois do conserto.
