## 4. Notas para o N1

- Nome do arquivo em cache = último segmento da URL (`<timestamp>-<nome>.pdf`, único por construção do upload B6-D5′); a chave de cache do PRD é a URL inteira — equivalente enquanto o bucket for um só.
- O `download-error` de `expo-file-system` sem rede é `Call to function 'FileSystem.downloadFileAsync' has been rejected.` com a causa Java em `→ Caused by:`; o `sync-error` do `fetch` do RN é `fetch failed: java.net.UnknownHostException …` — duas formas para a mesma condição, a camada de rede única do N1 normaliza (T1-R37).
- O `Voltar` do `PdfProbe` precisou de `paddingBottom: 72` para não ficar sob a barra de navegação do sistema em landscape — alvo ≥ 48 px nas bordas (T1-R27) exige `SafeAreaView`/insets no N1.
- `adb shell run-as` funciona no build de debug — instrumento de A9 no aceite.
