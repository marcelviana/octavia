   * **Regra 2 do catálogo**: URL completa nunca entra em log. A mensagem crua
   * da biblioteca carrega a URL do objeto (`Unable to download file from
   * <url>. Response status: 404`), então ela é traduzida quando se reconhece a
   * causa e higienizada quando não.
   */
  function falha(erro: unknown, name: string): Error {
    if (erro instanceof Error && erro.message.startsWith(`${name}: `)) return erro
    const bruta = erro instanceof Error ? erro.message : String(erro)
    const status = /status:?\s*(\d{3})/i.exec(bruta)?.[1]
    if (status !== undefined) return new Error(`${name}: o servidor respondeu ${status}`)
    return new Error(`${name}: ${bruta.replace(/https?:\/\/\S+/g, '<url>')}`)
  }

§4. O `gate:a20` ALCANÇA A INTERCEPTAÇÃO?
--------------------------------------------------------------------------------
Não, e o motivo não é escopo — é natureza.

  O `a20.mjs` acusa LITERAL em posição de texto (`<Text>…</Text>`,
  `accessibilityLabel=`, `placeholder=`, `chave: '…'`, `Alert.alert(`). A
  mensagem da div. 125 **não é literal em lugar nenhum**: é um valor de tempo
  de execução que vem da biblioteca. Pôr o `App.tsx` no escopo do a20 (o
  conserto da div. 123) **não a alcança**. Varrer `apps/native` inteiro também
  não. Nenhum escopo alcança.

  => O `gate:a20` tem escopo menor do que o ACEITE que ele representa. O A20 do
     PRD diz "nenhum literal de UI em inglês"; o que chega à tela do músico é
     texto de UI em inglês que não é literal. É o mesmo erro do padrão do
     `LOGS-OCTAVIA.md`, num lugar novo — ler o que o instrumento mede como se
     fosse o que se queria saber. **Div. 130.**

  O QUE ALCANÇA, e agora é possível porque o W1 abriu o projeto `native` do
  vitest:
    • um teste de unidade sobre `falha()` — hoje ela não é exportada, o que é
      uma linha de `export`: dado um Error com mensagem arbitrária, o que sai
      tem de estar num conjunto FECHADO de frases em pt-BR;
    • e um gate de verdade: a lista de frases que podem chegar ao
      `testID="download-erro"` é finita e declarada — o mesmo formato da lista
      de erratas do G3, que é o escopo escrito no próprio script.

§5. O QUE É DECISÃO DE TEXTO DE UI, E PORTANTO DO MARCEL
--------------------------------------------------------------------------------
  1. A frase genérica do ramo 3. Candidata: "não foi possível baixar agora"
     (o catálogo já traduz `download-error` por *"não consegui baixar"*,
     `LOGS-OCTAVIA.md:396`) — mas a escolha é dele.
  2. **O nome do arquivo na tela.** Hoje o S3e mostra
     `1751910900697-Easy_-_Guitar.pdf: <mensagem>` — o prefixo `${name}: ` do
     `falha()` vai junto. O nome do objeto no bucket não é vocabulário de
     músico. Separar "o que vai para o log" de "o que vai para a tela" é
     decisão de produto, não de código.
  3. Se o texto cru deve sobreviver em ALGUM lugar. Recomendação: sim, no log
     (é o que faz um relatório ser diagnosticável), e não na tela.
