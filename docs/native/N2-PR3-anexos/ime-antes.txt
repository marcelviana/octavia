POR QUE O CN É DE APARELHO, E NÃO DE TELA
  O projeto `native-tela` roda em `jsdom` com um duplo de `react-native`
  (`test/fake-react-native.tsx`). O duplo do `Modal` é:

      export function Modal(p) {
        if (p.visible === false) return null
        return createElement('div', {...atributos(p), 'data-modal':'true'}, p.children)
      }

  — ele ignora `onShow`, e `jsdom` não tem IME. **Nenhum teste de tela pode
  reprovar aqui**, nem antes nem depois do fix. Por isso o CN é este dumpsys.
