    const bruta = erro instanceof Error ? erro.message : 'falha ao baixar'

§2. O CONJUNTO QUE ESCAPA DO `falha()` — ENCOLHEU, NÃO ZEROU
--------------------------------------------------------------------------------
A W2 pôs a promoção do `ensureFileUma` num `try` (div. 131, classe 2). Sobrou,
lido no código:

  `ensureFileUma`  linhas 189-191 — `fileNameFromUrl`, `dirGarantido()`/
                   `dirDemanda()`, o primeiro `localizar(url)`
                   linhas 211-214 — o segundo `localizar()`, o `.size`, o
                   `touch(url)` e o `log()`
  `baixarAtomico`  a ABERTURA: `const parcial = new File(...)` e
                   `if (parcial.exists) parcial.delete()` estão **antes** do
                   `try`

Qualquer rejeição desses pontos sobe crua até o `catch` do `baixar()` do
`prefetch.ts` e sai pelo `mensagemDe()`.

§3. COMO SE MEDE UMA REDE — O `__quebrarDelete`
--------------------------------------------------------------------------------
O teste alcança o `parcial.delete()`: um `.part` velho plantado no durável, e um
`delete()` que recusa com a mensagem crua que se quiser. É um gancho novo no
duplo (`apps/native/test/fake-expo-file-system.ts`), e só existe para isto — o
`__quebrarMove` que já havia não serve mais, porque a W2 pôs o `moveSync` sob o
`falha()`.

Quatro `it`, em `prefetch-fila.test.ts`:

  ✓ o HOST NU entre aspas não chega ao log — era o buraco da higienização antiga
  ✓ a URI `file://` continua coberta — unificar não podia custar cobertura
  ✓ a URL completa continua coberta
  ✓ CONTROLE NEGATIVO: o que NÃO é segredo sobrevive inteiro

O último é o que impede o conserto de virar exagero: `w3-curto-1.pdf.part`
sobrevive. Apagar o nome do arquivo do log destruiria a diagnosticabilidade que
a separação das duas metades (W2) comprou — é o mesmo limite que o `files.ts`
já declara para o host de dois rótulos.

§6. O QUE MUDA NO LOG, E O QUE NÃO MUDA
--------------------------------------------------------------------------------
G3: 57 = 57. **Nenhuma linha `log(` mudou** — logo SEM errata de gate, e sem
linha nova no catálogo. O `log(\`download-error ${mensagemDe(erro)}\`)` é o
mesmo caractere por caractere; o que mudou é o que a função devolve.

Os rótulos também não mudam de vocabulário: `<url>` para `http(s)`, `<uri>` para
`file:`, `"<host>"` para o host nu — cada um já era o que o seu lado usava. O que
esta PR fez foi dar a cada lado o que só o outro tinha.
