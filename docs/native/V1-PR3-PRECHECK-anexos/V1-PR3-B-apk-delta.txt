===== B6 — o que este APK NÃO mede =====
É `assembleDebug`, que é o que o CI produz e o que se instala no aparelho para
desenvolver. **Não** é release: sem minify, sem `shrinkResources`, sem R8, com
as 7 fontes e o menu do `expo-dev-menu` dentro. O Δ de um APK de release do
`react-native-svg` seria menor — e o Octavia não tem pipeline de release hoje,
então o número que importa para o Tab S6 é este.
