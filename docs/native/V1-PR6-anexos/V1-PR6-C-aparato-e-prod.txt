===== C2 — o avião provado por `ping`, quatro vezes =====

  A regra do bloco: avião não é o valor do setting, é o `ping` falhando. O
  setting é lido junto, mas quem prova é a segunda linha.

  PROVA 0 — o estado em que o AVD foi encontrado (rede VIVA, e é por isso que
  a prova existe):
    $ adb -s emulator-5554 shell settings get global airplane_mode_on
    0
    $ adb -s emulator-5554 shell "ping -c 2 -W 2 8.8.8.8"
    2 packets transmitted, 2 received, 0% packet loss, time 1001ms
    rtt min/avg/max/mdev = 46.266/129.704/213.142/83.438 ms

  Corte: `settings put global airplane_mode_on 1` + broadcast AIRPLANE_MODE.

  PROVA 1 — logo depois do corte, ANTES de qualquer abertura:
    setting=1
    connect: Network is unreachable

  PROVA 2 — depois do `adb reverse`, ANTES da abertura do ANTES:
    setting=1
    connect: Network is unreachable

  PROVA 3 — ANTES da abertura do DEPOIS (bundle dos quatro commits):
    setting=1
    connect: Network is unreachable

  PROVA 4 — ao fim de toda a medição:
    setting=1
    connect: Network is unreachable

  O `adb reverse tcp:8081 tcp:8081` atravessa o avião porque não é rede: é o
  canal do adb. É por isso que o Metro serve o bundle com a rede cortada.

===== C3 — AVD: antes × depois =====

  AVD `octavia_tab32` (API 32, pixel_tablet), `-port 5554` obrigatório (div. 20),
  subido SEM `-no-snapshot-save` (div. 42).

    $ adb -s emulator-5554 shell wm size     → Physical size: 2560x1600
    $ adb -s emulator-5554 shell wm density  → Physical density: 360
    2560×1600 @ 360 dpi = 1138 × 711 dp, idêntico ao Tab S6.

  Dois ciclos completos nesta sessão:
    boot 1 → medição ANTES e DEPOIS → `emu kill` (22,6 s salvando o snapshot)
    boot 2 → medição do store DURÁVEL → `emu kill`

  Encerramento, pela div. 75, nos dois tempos e nesta ordem:
    1. `adb -s emulator-5554 reverse --remove-all` — e a lista fica vazia;
    2. `lsof -ti:8081 | xargs ps -o pid,command -p` ANTES de matar nada:
         37948 node .../expo/bin/cli start --port 8081      ← o Metro
         38051 adb -L tcp:5037 fork-server server           ← o SERVIDOR ADB
       Este segundo PID é a lição inteira: um `lsof -ti:8081 | xargs kill -9`
       teria levado o adb junto. Depois do `--remove-all` o qemu não aparece
       mais, que é o outro lado da mesma regra.
    3. `pkill -f "expo/bin/cli start"` — pelo comando, não pelo PID da porta;
    4. 8081 livre, conferido;
    5. `emu kill`, que salva o snapshot.

  Estado em que o AVD FICA, e a diferença declarada: **modo avião LIGADO**
  (`airplane_mode_on = 1`), onde foi encontrado com 0. Deixei ligado de
  propósito: reduz o risco de um sync acidental contra o teto de 2 requests que
  a V1-PR7 herda. **Isso não dispensa a prova**: a sessão seguinte tem de rodar
  o `ping` do mesmo jeito, porque o setting nunca foi a evidência.
